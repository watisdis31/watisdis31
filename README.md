## About

I'm a fullstack developer building web apps and business systems that real teams rely on every day. I care about making things that are fast, clear, and actually make people's work easier. Whether it's a landing page, a dashboard, or a full system, I want to build software that helps businesses grow.

Before tech, I spent years in F&B as an Assistant Operations Manager, so I know what it's like to run a business on the ground. That's why I build with the people using it in mind.
